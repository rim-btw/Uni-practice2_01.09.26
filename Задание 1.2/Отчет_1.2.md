## 2. Постановка задачи

## 3. Исследование способов автоматизации

В ходе работы были рассмотрены следующие подходы к автоматизации установки ПО под Windows:

- **Пакетные файлы (.bat)** — самый простой способ. Скрипт содержит последовательность команд, которые выполняются в командной строке. Подходит для запуска установщиков `.exe` и `.msi` с ключами тихой установки.
- **MSI-пакеты** — установка через `msiexec` с параметрами `/quiet` и `/norestart`. Позволяет полностью автоматизировать процесс без участия пользователя.
- **Пакетный менеджер WinGet** — встроен в Windows 10/11, позволяет устанавливать ПО из официального репозитория Microsoft одной командой `winget install`. Автоматически скачивает дистрибутивы с официальных сайтов производителей.
- **Chocolatey** — сторонний пакетный менеджер, требующий предварительной установки. Используется в организациях для массового развёртывания ПО.

Для выполнения задания был выбран **WinGet**, так как он не требует установки дополнительного ПО и уже присутствует в системе.

## 4. Комментарии по выполнению
Скрипт написан на языке пакетных файлов Windows (.bat).

В начале скрипта выполняется проверка прав администратора: без них winget не сможет устанавливать программы.

Проверяется наличие winget в системе. Если утилита отсутствует, скрипт сообщает об этом и завершает работу.

Для каждого приложения вызывается функция :installApp, которая:

выводит название, ID пакета и ссылку на официальный сайт;

проверяет, установлено ли приложение (через winget list);

если не установлено — запускает установку в тихом режиме;

если установлено — пропускает.

Флаги --silent, --accept-source-agreements, --accept-package-agreements и --disable-interactivity обеспечивают полностью автоматическую установку без участия пользователя.

В отчёте использованы официальные ссылки на сайты производителей (из PDF-списка).

По окончании работы выводится итоговое сообщение с датой и временем.

## 6. Листинг скрипта

::  Пакетный менеджер: WinGet (встроен в Windows 10/11)

    echo.
    echo ============================================================
    echo    ТРЕБУЮТСЯ ПРАВА АДМИНИСТРАТОРА

:installApp

winget list --id %APP_ID% --exact > temp_check.txt 2>&1

    echo Статус: не установлено. Начинаю установку...
